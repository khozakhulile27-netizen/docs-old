  # tscircuit Repositories

  tscircuit is made up of many repositories. Here's an overview of the key repos and what they do.

  ## Core

  | Repository | Description |
  |---|---|
  | [tscircuit/tscircuit](https://github.com/tscircuit/tscircuit) | Main package — the `tscircuit` npm package and CLI |
  | [tscircuit/core](https://github.com/tscircuit/core) | Core rendering engine that converts TSX/JSX into circuit JSON |
  | [tscircuit/circuit-json](https://github.com/tscircuit/circuit-json) | Zod schemas and types for the Circuit JSON spec |

  ## Viewers & UI

  | Repository | Description |
  |---|---|
  | [tscircuit/pcb-viewer](https://github.com/tscircuit/pcb-viewer) | Interactive PCB board viewer React component |
  | [tscircuit/schematic-viewer](https://github.com/tscircuit/schematic-viewer) | Interactive schematic viewer React component |
  | [tscircuit/3d-viewer](https://github.com/tscircuit/3d-viewer) | 3D PCB viewer using Three.js |
  | [tscircuit/runframe](https://github.com/tscircuit/runframe) | Embeddable circuit preview iframe component |

  ## Routing & Layout

  | Repository | Description |
  |---|---|
  | [tscircuit/autorouting](https://github.com/tscircuit/autorouting) | PCB autorouter algorithms |
  | [tscircuit/schematic-trace-solver](https://github.com/tscircuit/schematic-trace-solver) | Schematic trace routing solver |

  ## Tools & Infrastructure

  | Repository | Description |
  |---|---|
  | [tscircuit/jlcsearch](https://github.com/tscircuit/jlcsearch) | JLCPCB component search API |
  | [tscircuit/kicad-component-converter](https://github.com/tscircuit/kicad-component-converter) | Converts KiCad components to tscircuit format |
  | [tscircuit/winterspec](https://github.com/tscircuit/winterspec) | API framework used by tscircuit services |

  ## How to Contribute

  1. Browse [open issues](https://github.com/issues?q=org%3Atscircuit+is%3Aopen+is%3Aissue) across all tscircuit repos
  2. Look for issues labelled **💎 Bounty** — these have cash rewards paid via [Algora](https://algora.io)
  3. Comment on an issue to claim it, then fork the repo and open a pull request
  4. Join the [Discord](https://discord.com/invite/V7FGE5ZCbA) to ask questions and get help from the team
